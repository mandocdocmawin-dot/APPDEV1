# Defense Notes
1. Read the target file.
2. Write one sentence on what the file does.
3. Pick the 3 most important lines and explain each simply.
4. List 2 mistakes a beginner might make here.
5. Write 3 questions a teacher could ask, without answers.
6. Do not edit the exercise file.
